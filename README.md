# ⚽ 스톡커 (Stoccer)

> **Stock + Soccer = Stoccer** — 축구 포메이션처럼 짜는 대한민국 주식 포트폴리오

주식의 재무 특성(매출·이익률·부채비율·배당성향·현금흐름 등)과 시장 특성(시가총액·변동성·MDD·PER/PBR·외국인비율 등)에 따라 종목을 축구 포지션으로 분류하고, 포메이션을 짜듯 포트폴리오를 구성하는 웹 앱입니다.

## 포지션 분류 체계

| 포지션 | 분류 기준 | 대표 업종 |
|---|---|---|
| **ST** 중앙 공격수 | 시총 50조+ 주도주, 포트폴리오 방향성 결정 | 반도체·자동차·배터리·바이오 |
| **LW/RW** 측면 공격수 | 주도주와 방향성 공유, 소형·고변동 엣지 수익원 | 장비·부품·핵심소재·의료 |
| **CAM** 공격형 미드필더 | 지속 성장 + 신사업 모멘텀 | 플랫폼·콘텐츠 |
| **CDM** 수비형 미드필더 | 안정 실적 + 신사업 모멘텀 | 종합식품·기호식품 |
| **CB** 중앙 수비수 | 저변동 + 고배당 | 통신·은행 |
| **LB/RB** 측면 수비수 | 사이클 업종, 매매로 공략 | 정유·화학·해운·철강 |
| **GK** 골키퍼 | 현금 | KRW |

## 주요 기능

- **스쿼드 빌더**: 4-3-3 / 4-4-2 / 3-4-3 / 5-4-1 포메이션 위에 종목 배치. 포지션 가중치에 따라 투자 비중 자동 배분, 현금(GK) 비중 슬라이더 조절
- **전문가 전술 복사**: 명장 × 투자 구루 프리셋 (퍼거슨×버핏 4-3-3, 무리뉴×달리오 5-4-1, 클롭×캐시우드 3-4-3, 과르디올라×린치 4-4-2)
- **그라운드 날씨**: 유가=온도, 금리=습도, 환율=풍향
- **스톡커 리그**: 일간 수익률 ±1%마다 득점/실점, 주간 수익률로 승(3)/무(1)/패(0) 승점 계산, 친구·벤치마크와 시즌 순위 경쟁 (현재는 시뮬레이션)

## 실행

```bash
npm install
npm run dev     # 개발 서버
npm run build   # 프로덕션 빌드
```

## 데이터

현재는 **개발용 샘플 데이터**로 동작합니다 (투자 권유 아님). 실데이터 연동 방법은 [docs/data-integration.md](docs/data-integration.md) 참고 — 한국투자증권 KIS Developers(실시간 WebSocket), KRX/pykrx(역대 시세), DART(재무), ECOS(금리·환율) 조합을 권장합니다. 연동 지점은 `src/lib/provider.ts`의 `DataProvider` 인터페이스입니다.

## 프로젝트 구조

```
src/
  data/stocks.ts      # 종목 스카우트 DB (포지션 분류 + 재무/시장 특성)
  data/formations.ts  # 포메이션 정의 + 포지션별 투자 가중치
  data/tactics.ts     # 전문가 전술 프리셋
  lib/league.ts       # 리그 규칙 엔진 (득점/승점 계산)
  lib/provider.ts     # 시세 데이터 프로바이더 추상화 (Mock → 실데이터 교체 지점)
  components/         # 경기장, 스카우트 모달, 리그, 날씨 UI
```
